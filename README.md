## 🏗️ Architecture — The Stack Under the Hood

```
ids-learning-lab/
│
├── 🎨 src/styles/          → Design token system (CSS Variables)
│   └── variables.css       → Single source of truth for all tokens
│
├── 🧩 src/components/      → 20+ reusable UI components
│   ├── Header.js           → Navigation shell
│   ├── LogViewer.js        → Raw log display engine
│   ├── TriageCard.js       → SOC decision interface
│   └── ...
│
├── 📄 src/pages/           → 18 pages (including full Admin suite)
│
├── 🧠 src/modules/         → Isolated business logic
│   ├── ctf/                → CTF engine + flag validator
│   ├── quiz/               → Question engine + scoring
│   ├── triage/             → Alert triage engine
│   ├── analytics/          → Event logger + progress tracker
│   └── assessment/         → Pre/Post test engine
│
├── 📦 src/data/            → All content lives here
│   ├── ctf/challenges/     → 30 CTF challenges (6 files × 5 flags)
│   ├── questions.js        → 50+ question bank
│   └── materials.js        → Meeting content & explanations
│
└── 🧪 tests/               → 36+ automated unit tests (zero deps)
```

**Principles:** `Zero UI framework` · `Zero backend` · `100% Local-First` · `LocalStorage persistence`

## 🚀 Get Started in 60 Seconds

```bash
# 1. Clone
git clone https://github.com/prasbara/INTERACTIVE-CYBERSECURITY-LEARNING.git

# 2. Install
cd INTERACTIVE-CYBERSECURITY-LEARNING
npm install

# 3. Launch
npm run dev
```

```
  Open http://localhost:3000
       │
       ├── You'll see a landing page
       ├── Create your SOC analyst identity
       ├── Take the pre-test (don't panic)
       └── Start Meeting 01 — good luck. 🎯
```

### Other commands

```bash
npm test          # Run 36+ unit tests
npm run build     # Build for production → /dist
npm run lint      # Audit code syntax
npm run preview   # Preview production build
```

## 🔒 Ethical Use

> All scenarios, logs, and CTF evidence are **100% synthetic**.

```diff
+ ✅ Learn to detect, analyze, and respond to threats
+ ✅ Practice in the simulated SOC environment
+ ✅ Build your critical thinking & investigation skills
- ❌ Do NOT attack real systems, networks, or services
- ❌ Do NOT target schools, government, or live infrastructure
```

*With great detection power comes great responsibility.* 🦸
